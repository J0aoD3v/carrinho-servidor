# Exame - Conteúdos

O exame de **Programação II** conterá questões sobre o conteúdo visto durante o ano.  
Serão propostos três tipos de questões:  

- **(a)** De múltipla escolha  
- **(b)** Discursivas  
- **(c)** De escrita de código  

A prova será baseada no livro:  
**SCHILDT, H. Java Para Iniciantes.** Porto Alegre: Bookman, 2015.  
Porém, nada impede de serem utilizadas outras fontes de estudo.

## Conteúdos

### 1. Classes e objetos  
   - **Criação de classes** e instanciação de objetos  
   - Construtores “vazios” e **parametrizados**  

### 2. Métodos  
   - Parâmetros  
   - Retorno  
   - Sobrecarga  
   - Chamada a métodos e passagem de parâmetros  

### 3. Modificadores de acesso  
   - `private`, `public`, `protected`, **padrão**  

### 4. Herança  
   - Definição de **herança**  
   - Implementação de **herança**  
   - **Sobrescrita** de métodos  
   - Classes **abstratas**  
   - **Polimorfismo** no contexto da herança de classes  

### 5. Interfaces  
   - Definição de **interfaces**  
   - **Criação** e utilização de interfaces  
   - **Polimorfismo** com interfaces  

### 6. Pacotes  
   - **Definição** de pacotes  
   - Influência de pacotes na **visibilidade** dos elementos  

### 7. Programação com tipos parametrizados  
   - **Criação** de classes genéricas  
   - **Instanciação** de objetos a partir de classes genéricas  

### 8. Tratamento de exceções  
   - **Definição** de exceções  
   - Consequência do **não tratamento**  
   - Diferença entre exceções **verificadas** e **não verificadas**  
   - Tratamento com `try/catch`  
     - Hierarquia de exceções e **múltiplos `catch`s**  
   - **Relançamento** de exceções (`throw` / `throws`)  
   - **Criação** de exceções personalizadas
